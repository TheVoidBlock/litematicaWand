# Simple mod that adds a dummy item for Litematica [Modrinth](https://modrinth.com/mod/litematicawand)
### No bs crafting recipies, just a simple dummy item.

For use on servers, I recommend using [NBT Editor](https://modrinth.com/mod/voidcommands), as it allows you to run ``` /vget litematicawand:wand ``` to get a ghost Litematica wand
