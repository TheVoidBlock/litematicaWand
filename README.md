# Litematica Wand
Simple mod that adds a dummy item for Litematica.

Access the item in the "Operator Utilities" creative tab. Enable this tab in `Options ➜ Controls ➜ Operator Items Tab`

You can also do ```/lwand``` to receive a ghost wand that will disappear upon interacting with. This is useful if you're playing in survival or on a server.

As of Litematica Wand 1.3.0 (26.2+), the wand item will work as your Litematica tool item regardless of what your Litematica config is set to.

<details>
<summary>Instructions on using Litematica Wand in older versions</summary>
<ol>
    <li>Access the Litematica config by either
        <ol>
            <li>Opening Litematica's main menu by pressing the keybind (default 'm'), and then clicking 'Configuration menu'.</li>
            <li>Clicking on Litematica's icon from Mod Menu.</li>
        </ol>
    </li>
    <li>Search for 'toolItem'</li>
    <li>Replace 'minecraft:stick' with 'litematicawand:wand'</li>
</ol>
</details>
