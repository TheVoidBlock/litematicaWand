# Litematica Wand [Modrinth](https://modrinth.com/mod/litematicawand)
## Simple mod that adds a dummy item for Litematica.

For use on servers, I recommend using [voidcommands](https://modrinth.com/mod/voidcommands), as it allows you to run ``` /get item litematicawand:wand ``` to get a ghost Litematica wand
